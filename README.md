# waystep-privacy

Privacy policy for the Waystep Android app, published with GitHub Pages.

- Live page: https://imahobostudios-lgtm.github.io/waystep-privacy/
- The policy is `index.md` (Markdown). Edit it, update "Last updated", commit and push;
  the page updates about a minute later.
- Keep it in step with the app: new permissions, SDKs or anything that sends data off the
  phone need a line here (and in Play Console → App content → Data safety).
